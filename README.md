# ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/aiza599/Programming-of-Ai-lab-Task.git
```

Navigate to the project:

```bash
cd Programming-of-Ai-lab-Task
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
